Lab 1: Introduction to C Programming (Week #1)

Master the foundational anatomy of a C program. Learn how to print formatted text to the screen using printf and read user keyboard input step-by-step using scanf.

Step 1.1: Printing "Hello World"

Every C program requires standard header directives, a main entry function, and a return statement. 

#include <stdio.h>

int main() {
    // Print Hello World to screen
    printf("Hello World!\n");
    return 0;
}

Syntax Breakdown:

  • #include <stdio.h>: Includes Standard Input Output header for printf.
  • int main(): Starting entry point of every executable C program.
  • \n: Newline escape character that moves cursor to the next line.
  • return 0;: Indicates successful execution to the operating system.

Step 1.2: Reading Input with scanf & Formatting

To read an integer or floating-point number, declare a variable and pass its memory address using the address-of operator (&) inside scanf. 

#include <stdio.h>

int main() {
    int age;
    float score;

    printf("Enter your age: ");
    scanf("%d", &age);

    printf("Enter your test score: ");
    scanf("%f", &score);

    printf("You are %d years old.\n", age);
    printf("Your score is: %.2f\n", score);

    return 0;
}

Lab 1: Common Coding Errors & Pitfalls

  • Forgetting & in scanf: Writing scanf("%d", age) instead of scanf("%d", &age) crashes the program.
  • Specifier Mismatch: Using %d for floats or %f for integers prints garbage values.
  • Missing Semicolons: Omitting semicolons at statement ends causes syntax errors.

Lab 2: Data Types, Operators, and IF statements (Week #2)

Detailed step-by-step guide to fundamental C data types (`int`, `float`, `char`), arithmetic operators (`+`, `-`, `*`, `/`, `%`), and basic `if` conditional statements.

Step 2.1: C Data Types & Format Specifiers

Variables must be declared with a data type before storing data in computer memory. 

#include <stdio.h>

int main() {
    int count = 10;          // Whole numbers (%d)
    float price = 19.99;     // Decimals (%f)
    char grade = 'A';        // Single character (%c)

    printf("Count: %d\n", count);
    printf("Price: $%.2f\n", price);
    printf("Grade: %c\n", grade);

    return 0;
}
Specifier Summary:
int : %d
float : %f
double : %lf
char : %c

Step 2.2: Integer Division vs. Modulo Operator (%)

Dividing two integers in C performs integer truncation, stripping decimals. The modulo operator % returns the integer remainder. 

#include <stdio.h>

int main() {
    int num1 = 17, num2 = 5;
    int quotient = num1 / num2;  // Yields 3
    int remainder = num1 % num2; // Yields 2

    printf("17 / 5 = %d\n", quotient);
    printf("17 %% 5 = %d\n", remainder);

    return 0;
}
Modulo Rule: The modulo operator (%) works strictly with integers. Attempting 5.5 % 2.0 causes a compilation error.

Step 2.3: Basic IF Statements

An if statement runs a block of code only if its condition evaluates to true.

#include <stdio.h>

int main() {
    int number;
    printf("Enter a number: ");
    scanf("%d", &number);

    if (number > 0) {
        printf("%d is positive!\n", number);
    }
    if (number % 2 == 0) {
        printf("%d is even!\n", number);
    }
    return 0;
}
Relational Operators:
  • == Equal to
  • != Not equal to
  • > Greater than
  • < Less than
  • >= Greater or equal
  • <= Less or equal

Lab 2: Common Coding Errors & Pitfalls

  • Confusing Assignment (=) with Comparison (==): Writing if (x = 5) assigns 5 to x instead of checking equality. Always use if (x == 5).
  • Integer Truncation: Dividing two integers like 5 / 2 evaluates to 2, discarding the fractional part.

Lab 3: Decision Making in C (if, if-else, Nested-if, Switch) (Week #3)

Step-by-step exploration of branching logic using if-else ladders, nested conditions, and multi-option switch statements.

Step 3.1: if-else and else-if Ladders

#include <stdio.h>

int main() {
    int mark = 85;

    if (mark >= 90) {
        printf("Grade: A\n");
    } else if (mark >= 80) {
        printf("Grade: B\n");
    } else if (mark >= 70) {
        printf("Grade: C\n");
    } else {
        printf("Grade: F\n");
    }
    return 0;
}

An else-if ladder checks conditions sequentially top-down. The moment one condition evaluates to true, its block runs and the remaining ladder is skipped.

Step 3.2: Switch Statements

#include <stdio.h>

int main() {
    int option;
    printf("Enter choice (1-3): ");
    scanf("%d", &option);

    switch(option) {
        case 1:
            printf("Selected Option 1\n");
            break;
        case 2:
            printf("Selected Option 2\n");
            break;
        case 3:
            printf("Selected Option 3\n");
            break;
        default:
            printf("Invalid selection!\n");
    }
    return 0;
}

Switch Rules:

  • Works with discrete integers or characters.
  • break; prevents execution from falling through to the next case.
  • default: handles unmatched choices.

Lab 3: Common Coding Errors & Pitfalls

  • Missing break; Statements: Omitting break; in a switch case causes execution to fall through and run subsequent case blocks unintentionally.
  • Dangling Semicolons: Writing if (x > 10); { ... } puts an empty statement on the condition, running the block regardless of whether x > 10.

Lab 4: Loops I (for loop, while loop, input validation) (Week #5)

Step-by-step masterclass on repetition constructs. Learn count-controlled for loops and condition-controlled while loops for input validation.

Step 4.1: Count-Controlled for Loop

#include <stdio.h>

int main() {
    int i;
    // Count from 1 to 5
    for (i = 1; i <= 5; i++) {
        printf("Iteration %d\n", i);
    }
    return 0;
}

For Loop Structure:

  • i = 1: Initialization (runs once).
  • i <= 5: Condition checked before each iteration.
  • i++: Increment step after each loop body run.

Step 4.2: Input Validation with while Loop

#include <stdio.h>

int main() {
    int val;

    printf("Enter a positive number (> 0): ");
    scanf("%d", &val);

    // Keep prompting until correct
    while (val <= 0) {
        printf("Invalid! Try again (> 0): ");
        scanf("%d", &val);
    }

    printf("Valid input accepted: %d\n", val);
    return 0;
}

Lab 4: Common Coding Errors & Pitfalls

  • Infinite Loops: Forgetting to re-scan or update the condition variable inside the loop body causes infinite execution.
  • Off-by-One Bounds: Writing i <= 5 instead of i < 5 when 5 iterations starting at 0 are desired.

Lab 5: Loops II (nested loops, multiplication tables, patterns) (Week #6)

Detailed step-by-step mechanics of nested loops (loops inside loops) to generate 2D grids, multiplication tables, and geometric patterns.

Step 5.1: Nested For Loops (Multiplication Table)

#include <stdio.h>

int main() {
    int i, j;

    // Outer loop: Rows
    for (i = 1; i <= 4; i++) {
        // Inner loop: Columns
        for (j = 1; j <= 4; j++) {
            printf("%3d ", i * j);
        }
        printf("\n"); // New row
    }
    return 0;
}

Step 5.2: Pattern Printing (Star Triangle)

#include <stdio.h>

int main() {
    int i, j;
    for (i = 1; i <= 5; i++) {
        for (j = 1; j <= i; j++) {
            printf("* ");
        }
        printf("\n");
    }
    return 0;
}

For row i, the inner loop runs i times, creating an increasing triangle pattern.

Lab 5: Common Coding Errors & Pitfalls

  • Reusing Loop Index Counters: Using i for both outer and inner loops corrupts the iteration sequence. Use i and j.
  • Forgetting Row Newlines: Omitting printf("\n"); after the inner loop prints all elements on a single line.

Lab 6: Functions (normal function, void function, int main) (Week #7)

Step-by-step modular code design using function prototypes, void functions, returning functions, and calling them inside int main().

Step 6.1: Prototypes, Void Functions & Returning Functions

#include <stdio.h>

// Function Prototypes
void printGreeting();
int square(int n);

int main() {
    printGreeting(); // Call void function
    
    int result = square(5); // Call returning function
    printf("5 squared is: %d\n", result);
    
    return 0;
}

// Void function implementation
void printGreeting() {
    printf("=== WELCOME TO LAB 6 ===\n");
}

// Returning function implementation
int square(int n) {
    return n * n;
}

Function Mechanics:

  • Prototype: Informs compiler of function name/parameters before main().
  • void: Indicates no value is returned.
  • return: Sends calculated result back to caller.

Lab 6: Common Coding Errors & Pitfalls

  • Implicit Declaration Warnings: Calling a function inside main() before prototyping or defining it triggers compiler warnings.
  • Missing Return Value: Declaring a function with return type int without a return statement returns garbage values.

Lab 8: Bubble Sort Algorithm Visualizer

Detailed step-by-step breakdown of Bubble Sort. Learn how adjacent pairs are compared and swapped using a temporary variable.

Step 8.1: Bubble Sort C Implementation & Swapping

#include <stdio.h>

int main() {
    int arr[5] = {64, 25, 12, 22, 11};
    int n = 5, i, j, temp;

    // Outer Loop: Passes
    for (i = 0; i < n - 1; i++) {
        // Inner Loop: Adjacent comparisons
        for (j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                // Swap logic using temp
                temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }

    // Print sorted array
    for (i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    return 0;
}
How Swapping Works:
1. temp = arr[j]; (Save A)
2. arr[j] = arr[j+1]; (Overwrite A with B)
3. arr[j+1] = temp; (Put saved A into B)

Lab 8: Common Coding Errors & Pitfalls

  • Swapping Without Temp: Writing a = b; b = a; overwrites a before saving its value, losing data.
  • Inner Loop Bounds Overrun: Using j < n instead of j < n - i - 1 in the inner loop causes arr[j+1] to access past array limits.
