Lab 1: Introduction to C Programming & Basics

Week #1

Learn the essential foundation of C programming through step-by-step progressive building blocks—from program structure to outputting numbers and receiving user input with printf and scanf.

Step 1 Minimum C Program Structure

Every C program requires standard input/output library headers (#include <stdio.h>) and an entry point int main(). 

#include <stdio.h>

int main() {
    // Every statement ends with a semicolon
    return 0; // Signals program finished successfully
}

Step 2 Basic Text Printing & Newlines (\n)

Use printf("..."); to output text. Use \n to jump to a new line. 

#include <stdio.h>

int main() {
    printf("Hello, World!\n");
    printf("Welcome to C Programming Lab.\n");
    printf("Line 1\nLine 2\nLine 3\n");
    return 0;
}

Step 3 Printing Integers & Floats (%d, %f)

Use format specifiers inside quotes: %d for integers (whole numbers) and %f or %.2f for floating point decimals. 

#include <stdio.h>

int main() {
    int age = 19;
    float score = 95.5;

    printf("Age: %d years old\n", age);
    printf("Exam Score: %f\n", score);
    printf("Formatted Score (2 decimals): %.2f\n", score);
    return 0;
}

Step 4 Reading Single Input with scanf()

Use scanf("%d", &variable); to read keyboard input into a variable. Always place & before the variable name! 

#include <stdio.h>

int main() {
    int userNumber;

    printf("Enter your favorite integer number: ");
    scanf("%d", &userNumber);

    printf("You entered the number: %d\n", userNumber);
    return 0;
}

Step 5 Reading Two Numbers & Calculating Sum

Prompt for two numbers sequentially, calculate their total sum, and print the resulting answer. 

#include <stdio.h>

int main() {
    int num1, num2, sum;

    printf("Enter first number: ");
    scanf("%d", &num1);

    printf("Enter second number: ");
    scanf("%d", &num2);

    sum = num1 + num2;

    printf("The total sum of %d + %d = %d\n", num1, num2, sum);
    return 0;
}

Lab 1 Common Errors & Syntax Mistakes

1. Missing Semicolon ';'

Forgetting a semicolon at statement ends breaks code compilation.

2. Missing '&' inside scanf()

Writing scanf("%d", x) leads to immediate program crash (Segmentation Fault).

3. Capitalization Errors

Writing Printf() or Int Main() causes errors. C is strictly lowercase for keywords!

4. Missing Header or Return

Forgetting #include <stdio.h> prevents C from finding printf or scanf.

Lab 2: Data Types, Operators, and IF Statements

Week #2 Homework 1

Learn primary data types (int, float, double, char), arithmetic operations, integer division vs floating division, and simple conditional decision making with if.

Example 1: Arithmetic & Division Trap

#include <stdio.h>

int main() {
    int a = 5, b = 2;
    int intResult;
    float floatResult;

    intResult = a / b;       // Integer division -> 2
    floatResult = 5.0 / 2.0; // Float division -> 2.50

    printf("Integer Division 5 / 2 = %d\n", intResult);
    printf("Float Division 5.0 / 2.0 = %.2f\n", floatResult);
    return 0;
}

Example 2: Simple IF Condition

#include <stdio.h>

int main() {
    int age;

    printf("Enter your age: ");
    scanf("%d", &age);

    if (age >= 18) {
        printf("You are eligible to vote!\n");
    }

    if (age < 18) {
        printf("You are too young to vote.\n");
    }

    return 0;
}

Lab 2 Common Errors & Bugs

  • 1. Confusing '=' with '==' inside IF

    if (x = 5) overwrites x with 5 and always evaluates to true! Use if (x == 5) for equality comparison.

  • 2. Integer Division Truncation

    Dividing integers discards decimal digits. 5 / 2 evaluates to 2. Use floats (e.g. 5.0 / 2) to keep decimals.

  • 3. Accidental Semicolon After IF Header

    Writing if (x > 5); { ... } runs the block unconditionally because the semicolon terminates the if immediately!

Lab 3: Decision Making in C (if, if-else, Nested-if, Switch)

Week #3 Homework 2

Branch program flow using binary choices (if-else), multi-tier conditions (else if), and discrete menu selection (switch-case).

Grade Classification (if-else if-else)

#include <stdio.h>

int main() {
    int mark;
    printf("Enter exam score (0-100): ");
    scanf("%d", &mark);

    if (mark >= 90) {
        printf("Grade: A\n");
    } else if (mark >= 80) {
        printf("Grade: B\n");
    } else if (mark >= 70) {
        printf("Grade: C\n");
    } else if (mark >= 60) {
        printf("Grade: D\n");
    } else {
        printf("Grade: F\n");
    }
    return 0;
}

Menu Choice (switch-case)

#include <stdio.h>

int main() {
    int choice;
    printf("1. Deposit\n2. Withdraw\n3. Exit\n");
    printf("Select option (1-3): ");
    scanf("%d", &choice);

    switch(choice) {
        case 1:
            printf("Deposit selected.\n");
            break;
        case 2:
            printf("Withdraw selected.\n");
            break;
        case 3:
            printf("Exiting program.\n");
            break;
        default:
            printf("Invalid selection!\n");
    }
    return 0;
}

Lab 3 Common Errors & Bugs

  • 1. Forgetting 'break;' in Switch Cases

    Omitting break; causes execution to "fall through" into every case below it unconditionally!

  • 2. Comparing Characters Without Quotes

    Character literals require single quotes, like 'A' or 'b'. Writing case A: treats A as an unassigned variable.

Lab 4: Loops I (for loop, while loop, input validation)

Week #5

Master repetition with for loops for fixed iteration counts and while loops for input validation that reprompts until valid input is given.

Counting 1 to 10 (for & while)

#include <stdio.h>

int main() {
    // 1. Standard FOR Loop
    printf("For Loop:\n");
    for (int i = 1; i <= 10; i++) {
        printf("%d ", i);
    }
    printf("\n\n");

    // 2. Equivalent WHILE Loop
    printf("While Loop:\n");
    int count = 1;
    while (count <= 10) {
        printf("%d ", count);
        count++; // Increment count
    }
    printf("\n");
    return 0;
}

Lab 4 Common Errors & Bugs

  • 1. Infinite Loops (Missing Increment)

    Forgetting count++ inside a while(count <= 10) loop causes the loop to run forever.

  • 2. Semicolon After Loop Header

    Writing while (x < 10); places an empty statement in the loop body, freezing execution right on that line.

Lab 5: Loops II (Nested Loops & Patterns)

Week #6

Nest loops inside loops to work with multi-dimensional structures: printing multiplication tables and star shape patterns.

Interactive Pattern & Table Visualizer

// Right Triangle Star Pattern
for (int i = 1; i <= 5; i++) {
    for (int j = 1; j <= i; j++) {
        printf("* ");
    }
    printf("\n"); // Newline after row completes
}

Lab 5 Common Errors & Bugs

  • 1. Reusing Same Counter Variable 'i'

    Using for(int i=0...) inside an outer loop that also uses i corrupts loop counters completely.

  • 2. Forgetting Row Newlines

    Forgetting printf("\n"); at the end of the inner loop prints all table or pattern items on one long single line.

Lab 6: Functions (Normal Functions & Void Functions)

Week #7

Divide programs into reusable, modular blocks using function prototypes, returning functions (int, float), and non-returning void functions.

Function Prototypes & Calls

#include <stdio.h>

// 1. Function Prototypes (Declarations)
void printHeader();
int calculateArea(int length, int width);

int main() {
    printHeader(); // Call void function

    int l = 5, w = 4;
    int area = calculateArea(l, w); // Call returning function

    printf("Area of %d x %d rectangle = %d\n", l, w, area);
    return 0;
}

// 2. Void Function Definition
void printHeader() {
    printf("=== RECTANGLE AREA CALCULATOR ===\n");
}

// 3. Returning Function Definition
int calculateArea(int length, int width) {
    return length * width;
}

Lab 6 Common Errors & Bugs

  • 1. Missing Function Prototypes

    Calling a function inside main() before declaring it triggers "implicit declaration" compiler warnings.

  • 2. Scope Misconception

    Variables defined inside main() are invisible inside other functions unless explicitly passed as parameters!

Lab 7: Arrays I (1D & 2D Arrays with Loops)

Week #9

Store sequence collections using 1D arrays and 2D grid matrices. Use for loops to read values with scanf and print array contents.

1D & 2D Array Reading & Printing

#include <stdio.h>

int main() {
    // 1D Array Example
    int numbers[5];
    printf("Enter 5 numbers:\n");
    for (int i = 0; i < 5; i++) {
        scanf("%d", &numbers[i]); // Note & before numbers[i]
    }

    printf("You entered: ");
    for (int i = 0; i < 5; i++) {
        printf("%d ", numbers[i]);
    }
    printf("\n\n");

    // 2D Matrix Array Example (2 rows, 3 columns)
    int matrix[2][3] = { {1, 2, 3}, {4, 5, 6} };
    printf("2D Matrix:\n");
    for (int row = 0; row < 2; row++) {
        for (int col = 0; col < 3; col++) {
            printf("%d ", matrix[row][col]);
        }
        printf("\n");
    }
    return 0;
}

Lab 7 Common Errors & Bugs

  • 1. Array Index Out of Bounds

    An array of size 5 (arr[5]) has valid indices 0 to 4. Accessing arr[5] accesses illegal memory!

  • 2. Forgetting '&' in scanf with Array Element

    Always write scanf("%d", &arr[i]);. Omitting & causes instant crashes.

Lab 8: Bubble Sort Algorithm

Algorithm Sorting

Bubble Sort steps through a 1D array, compares adjacent elements, and swaps them using a temp variable if they are out of order.

Interactive Bubble Sort Visualizer

Array Bars: Ready

12
88

5
#include <stdio.h>

int main() {
    int arr[5] = {34, 12, 88, 25, 5};
    int n = 5, temp;

    // Bubble Sort nested loops
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                // Swap using temp variable
                temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
    return 0;
}

Lab 8 Common Errors & Bugs

  • 1. Inner Loop Bounds (j + 1 Overflow)

    Writing j < n causes arr[j + 1] to access memory out of bounds! Always use j < n - 1 - i.

  • 2. Swapping Without 'temp'

    Writing arr[j] = arr[j+1]; arr[j+1] = arr[j]; overwrites value 1 before saving it! Always use a temporary variable.
