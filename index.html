Lab 1: Introduction to C Programming (Week #1)

Master the foundational anatomy of a C program. Learn how to print formatted text to the screen using printf and read user keyboard input step-by-step using scanf.

Step 1.1: Printing "Hello World"

Every C program requires standard header directives, a main entry function, and a return statement. 

#include <stdio.h>

int main() {
    // Print Hello World to screen
    printf("Hello World!\n");
    return 0;
}

Syntax Breakdown:

  • #include <stdio.h>: Includes Standard Input Output header for printf.
  • int main(): Starting entry point of every executable C program.
  • \n: Newline escape character that moves cursor to the next line.
  • return 0;: Indicates successful execution to the operating system.

Step 1.2: Reading Input with scanf & Formatting

To read an integer or floating-point number, declare a variable and pass its memory address using the address-of operator (&) inside scanf. 

#include <stdio.h>

int main() {
    int age;
    float score;

    printf("Enter your age: ");
    scanf("%d", &age);

    printf("Enter your test score: ");
    scanf("%f", &score);

    printf("You are %d years old.\n", age);
    printf("Your score is: %.2f\n", score);

    return 0;
}

Lab 1: Common Coding Errors & Pitfalls

  • Forgetting the address-of operator (&) in scanf: Writing scanf("%d", age) instead of scanf("%d", &age) causes crash/segmentation fault.
  • Format Specifier Mismatch: Using %d for floats or %f for integers yields incorrect values.
  • Forgetting double quotes or semicolons: Every standard statement in C must end with a semicolon (;).

Lab 2: Data Types, Operators, and IF statements (Week #2 - HW 1)

Learn C variable data types (`int`, `float`, `char`), arithmetic operators (`+`, `-`, `*`, `/`, `%`), and basic conditional decision branch statements.

Data Types & Integer Division vs Modulo 

#include <stdio.h>

int main() {
    int num1, num2;
    int quotient, remainder;

    printf("Enter two integers: ");
    scanf("%d %d", &num1, &num2);

    quotient = num1 / num2;  // Integer Division
    remainder = num1 % num2; // Modulo Operator

    printf("Quotient: %d\n", quotient);
    printf("Remainder: %d\n", remainder);

    // Basic IF Statement
    if (remainder == 0) {
        printf("%d is perfectly divisible by %d\n", num1, num2);
    }

    return 0;
}
Standard Format Specifiers:
int : %d
float : %f
double : %lf
char : %c
Modulo Rule (%): The modulo operator (%) calculates remainder after division and works only with integers.

Lab 2: Common Coding Errors & Pitfalls

  • Confusing Assignment (=) with Equality Comparison (==): Writing if (x = 5) assigns 5 to x instead of checking equality. Always use if (x == 5).
  • Integer Truncation Division: Dividing two integers like 5 / 2 yields 2 instead of 2.5.
  • Modulo on Floats: Attempting 5.5 % 2.0 causes a compiler compile error.

Lab 3: Decision Making in C (Week #3 - HW 2)

Explore complex control flow using if, if-else, Nested-if, and multi-branch switch statements.

Multi-Way Decision Control Structures 

#include <stdio.h>

int main() {
    int choice;
    printf("Enter choice (1-3): ");
    scanf("%d", &choice);

    // Switch Statement Structure
    switch(choice) {
        case 1:
            printf("Selected Option 1\n");
            break;
        case 2:
            printf("Selected Option 2\n");
            break;
        case 3:
            printf("Selected Option 3\n");
            break;
        default:
            printf("Invalid selection!\n");
    }
    return 0;
}
Decision Flow Logic Rules:
  • if-else ladder tests conditions sequentially top-down.
  • switch compares an integer expression directly against exact case constants.
  • break; statement exits the switch block immediately.
Switch Limit: switch expressions must evaluate to integral values (`int` or `char`), not floats.

Lab 3: Common Coding Errors & Pitfalls

  • Missing break; in switch cases: Forgetting break; causes execution to "fall through" into subsequent cases.
  • Dangling Semicolon on IF statement: Writing if (x > 10); { ... } terminates condition immediately and executes block regardless.

Lab 4: Loops I (for & while loops, input validation) (Week #5)

Master repeating code blocks using for loops and while loops. Learn how to repeatedly prompt and validate user input until correct data is provided.

Repeated Input Validation Loop Logic 

#include <stdio.h>

int main() {
    int num;

    printf("Enter a positive number (> 0): ");
    scanf("%d", &num);

    // Validate input repeatedly till correct
    while (num <= 0) {
        printf("Invalid input! Try again: ");
        scanf("%d", &num);
    }

    printf("Validation successful! You entered: %d\n", num);
    return 0;
}

Lab 5: Loops II (Nested Loops) (Week #6)

Learn multi-dimensional loop execution using nested for and while loops to generate grid patterns, multiplication tables, and geometric shapes.

Multiplication Table & Grid Generation 

#include <stdio.h>

int main() {
    int i, j;

    // Outer loop controls rows (i)
    for (i = 1; i <= 5; i++) {
        // Inner loop controls columns (j)
        for (j = 1; j <= 5; j++) {
            printf("%3d ", i * j);
        }
        printf("\n"); // Move to next row
    }
    return 0;
}

Lab 6: Modular Functions (Week #7)

Learn modular program design by creating user-defined functions, function prototypes, void helper functions, and value-returning functions called inside int main().

Function Prototypes, Void Functions & Main Execution 

#include <stdio.h>

// Function Prototypes
void printHeader();
int calculateSquare(int n);

int main() {
    int val = 5;
    int result;

    printHeader(); // Call void function
    result = calculateSquare(val); // Call returning function

    printf("Square of %d is: %d\n", val, result);
    return 0;
}

// Void Function implementation
void printHeader() {
    printf("=== MATH CALCULATOR ===\n");
}

// Value Returning Function implementation
int calculateSquare(int n) {
    return n * n;
}
Function Anatomy Rules:
  • Prototype: Declares function signature at top so main recognizes it before definition.
  • Void Function: Performs side effects (like printing) and returns no value.
  • Return Type: Specifies type of data sent back to caller via return.
Parameter Pass-by-Value: Variables passed into functions are copies. Modifications inside function do not alter main variables.

Lab 6: Common Coding Errors & Pitfalls

  • Implicit Declaration Warning: Calling a function in main() before defining or prototyping it above cause implicit declaration errors.
  • Missing Return Statement: Defining a non-void function (e.g., int add()) without a return statement yields garbage data.

Lab 7: Arrays I (1D & 2D Arrays) (Week #9)

Learn how to store multiple elements in sequential memory using 1D and 2D arrays. Use scanf loops to fill array elements and printf loops to display them.

Reading & Printing Array Elements in Loops 

#include <stdio.h>

int main() {
    int arr[5];
    int i;

    // Scanf in Loop to populate 1D Array
    printf("Enter 5 integers:\n");
    for (i = 0; i < 5; i++) {
        printf("Element [%d]: ", i);
        scanf("%d", &arr[i]);
    }

    // Print in Loop
    printf("\nStored Array Elements:\n");
    for (i = 0; i < 5; i++) {
        printf("arr[%d] = %d\n", i, arr[i]);
    }

    return 0;
}
Zero-Based Indexing Concept:

An array declared as int arr[5] creates 5 memory slots indexed strictly from 0 to 4.

index 010
index 125
index 242
index 37
index 499
2D Array Access: For a 2D array int matrix[2][3], access element at row r and column c using matrix[r][c] inside nested loops.

Lab 7: Common Coding Errors & Pitfalls

  • Array Index Out of Bounds: Accessing arr[5] on a size 5 array (int arr[5]) accesses unallocated memory resulting in garbage data or memory access crashes.
  • Forgetting & in Array Scanf: Writing scanf("%d", arr[i]) instead of scanf("%d", &arr[i]) causes crash.

Lab 8: Bubble Sort Algorithm Visualizer

Understand how Bubble Sort repeatedly steps through an array, compares adjacent pairs, and swaps them if they are in the wrong order until sorted.

Bubble Sort C Program & Swapping Logic 

#include <stdio.h>

int main() {
    int arr[5] = {64, 25, 12, 22, 11};
    int n = 5;
    int i, j, temp;

    // Outer Loop: Controls Number of Passes
    for (i = 0; i < n - 1; i++) {
        // Inner Loop: Compare adjacent elements
        for (j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                // Swap logic using temp variable
                temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }

    // Print sorted array
    for (i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    return 0;
}
How Variable Swapping Works:

To swap values of two variables without losing data, use a temporary variable temp:

1. temp = arr[j]; Save A into Temp
2. arr[j] = arr[j+1]; Overwrites A with B
3. arr[j+1] = temp; Restores Temp into B
Efficiency Note: After each pass $i$, the largest unsorted element "bubbles up" to its correct position at the end.

Lab 8: Common Coding Errors & Pitfalls

  • Swapping Without Temp Variable: Writing a = b; b = a; overwrites a before saving it, causing both variables to hold b's original value.
  • Inner Loop Bounds Overrun: Using j < n instead of j < n - i - 1 in inner loop causes arr[j+1] to read past array boundary.
